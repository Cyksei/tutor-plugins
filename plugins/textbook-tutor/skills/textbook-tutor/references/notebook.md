# Obsidian 单文件课程笔记

## 目录、确认和教材附件

本机目录：先按 [本机目录设置](storage-setup.md) 读取默认值；恢复旧课保留原位置，新课程使用本次指定位置或已保存的默认位置。首次未设置时先完成可单独运行的目录设置。下面的占位符在展示前必须替换为本机实际绝对路径。
每门新课程确认一次目录；同一课程后续使用已经确认的目录。尚未确认时可读教材，但不创建该课文件或复制教材。不得在这一步要求用户重复批准本次已明确指定的路径。

### 选项确认规则

路径确认是课程保存位置的选择，使用真实的可点击输入控件。优先调用 `functions.request_user_input_async`，不要把纯文字列表或 Markdown 复选框当作已创建的交互按钮。例如（将标题中的目录替换成实际当前路径）：

```json
{
  "questions": [{
    "title": "这门新课程保存到以下目录吗？\n<本机已确认的 Lessons 绝对路径>",
    "options": ["沿用当前路径（推荐）", "更改路径"]
  }]
}
```

- 用户点击并提交“沿用当前路径”后直接继续，不要求额外打字确认。
- 用户选择“更改路径”时，如已附上新路径则直接使用；否则仅此时询问新路径。若当前上下文已有用户明确提供的替代目录，可作为可点击候选；不能猜测目录或承诺不存在的原生文件夹选择器。
- 工具调用不等待回复时，继续可独立进行的教材读取，保存相关操作保持待确认。预选第一项不等于用户提交，也不能因超时而自行确认。
- 该工具不可用时，只在当前模式允许时使用另一真实选项输入工具；如都不可用，明确说明当前环境无法显示可点击选项，再作简短文字确认，不伪装按钮。
- 这是课程路径偏好选择，不替代运行环境的文件写入授权；已明确指定本课程路径时不重复弹选项。

目录结构示意（课程实际建立时才创建）：

```text
Lessons/
  课程名或教材中文名.md
  教材原文件名.pdf
```

每门课程一个 Markdown 文件，直接位于所选目录，所有章节重点、课堂笔记和错题都在其中，不另建章节文件、课次文件、索引数据库或隐藏进度目录。本机目录偏好配置仅保存设置，不属于课程笔记或学习进度。教材可有多个原格式附件，同级存放并分别链接。

优先使用用户指定的课程名；否则用经教材确认的中文标题。只有外文标题时使用准确、简洁的中文译名，在笔记注明原名和“译名”，不要冒充官方中文名。保留合法中文，替换文件名中的路径分隔符/控制字符，不把标题当作路径。不同课程或版本重名时加版本、学期或简短区分后缀，不能覆盖已有内容；现有文件确属同一课程时恢复并更新，不重复创建。

将提供的教材文件复制至确认目录，保留原始文件和扩展名。文件已在目标目录时核对身份后直接使用。目标有同名附件时比较内容哈希；相同则复用，不同则加区分后缀，不覆盖。复制后校验源/副本大小和 SHA-256；iCloud 文件尚未下载或源不可读时如实记录，不创建空教材冒充副本。

在笔记顶部用标准 Markdown 相对超链接引用同级教材，例如 `[教材：《线性代数》](%E7%BA%BF%E6%80%A7%E4%BB%A3%E6%95%B0.pdf)`。依据实际文件名进行 UTF-8 URL 编码，特别处理空格、括号、`#`、`%`，保留文件路径结构；不要把 shell 转义串、临时下载地址或原文件绝对路径当成最终教材链接。多个附件逐一链接。核对链接解码后确实指向目标文件。需要页码时可另外添加有明确文件页码的 PDF 页链接，保留基础链接。

只有粘贴文本时，可将用户实际提供的文本保存为同级 `.txt` 教材附件并标明范围；只有网页或远程来源时使用可用导出/下载能力取得真实附件，否则说明尚未取得本地教材并索取文件，不编造下载成功。复制教材不等于阅读教材。

## 单文件内容结构

可使用简短 YAML frontmatter 记录 `course_id`、`course_title`、`source_title`、版本、确认的 `lessons_dir`、教材相对文件名及哈希、更新时间。文件已有 frontmatter 时保留无关字段；源文件绝对路径仅作必要溯源，主教材链接始终指向同级附件。课程 ID 是安全稳定的标识，不能用来替代用户要求的中文文件名。

按以下内容组织标题，可随实际教材调整小节，但不省略记录职责：

1. **教材与课程信息**：教材超链接、原标题/版本、范围与课程目标。
2. **当前进度**：备课状态、当前章节/小节/重点、实际待答问题、相关错题 ID、下一步及更新时间。
3. **全书概览**：学习目标、知识主线、章节顺序及依赖。
4. **章节重点与课堂笔记**：依原书章/节顺序，每章分别列“备课详细重点”和“课堂记录”。重点按全书备课规则展开并附原文位置；课堂记录按实际日期/课次写入已讲内容、必要条件、推理、例子和学生得出的结论。未讲部分不得写成已讲。
5. **错题与复习**：稳定错误 ID、关联章/节、题目/情境、学生实际回答、具体错误、已给提示、已讨论的纠正与自我修正、复习状态和证据。
6. **备课覆盖记录**：教材身份与完整范围、分批读过/未读/缺失/不可读的位置、下一未读处及整理状态。全内容阅读及全部章节重点完成后才标记准备就绪。

各章可增加“联网补充与来源”小节，记录实际采用的研究/现实案例、与本章重点的联系、证据状态（如预印本/已评议/官方更新）、必要的适用条件，以及可点击来源链接、来源标题/作者或机构、发表/更新日期和本次检索日期。日期未知则注明未知。标记备课补充或已讨论；时效性事实重用前核查并更新检索日期，保留有教学意义的旧结论修正记录。不得另建课程外的研究笔记来替代此单文件，也不整篇转载外部文章。

首次创建时可以只写已知课程信息、教材链接和“备课中/尚未授课”；其他内容随着实际通读和教学补充。不要给未读章节预填编造重点。章节很多时全部重点仍保存在同一文件，使用标题和目录便于定位。

## 苏格拉底式教学与错误证据

课堂笔记只记录实际发生的内容；学生答案只有确切原话才加引号，否则标为忠实摘要。区分学生自我纠正和私教提供的结论，不推断没有证据的错误原因。没有错答就注明暂无记录，不造错题。

状态使用待纠正、提示后改正、独立改正、迁移检验通过，并写对应证据。不把没回答、提出问题或“我不知道”直接当作错误；可列为待澄清/未尝试。看过答案或说“懂了”不等于掌握。

待答的苏格拉底式问题不能提前把答案写进可见笔记；先记录问题、学生的已有回答及实际提示，待纠正讨论完成后才写解法。同类错误复现时更新同一条目并关联新课次，保留首次错误和修正历史。之后复习先让学生尝试，不先展示已记录解答，除非用户要求。

## 专用工具保存

已启用课程工具时遵循 [工具规则](course-tools.md)：学习事件与结构化状态在原课程 Markdown 中一次保存，专用状态块不另建数据库。工具按真实 section_path 将新记录写入对应章节、同步最新进度块，并按 error_id 归集错题证据；保留事件 ID、手工内容和状态块。首次处理旧版进度会标记为保留参考，不能把旧摘要当最新位置。

## 持续更新和恢复

每批备课、重要概念、错答/纠正、章节变更及下课时更新同一个文件。先读取当前版本；写入前检查是否有用户或同步产生的更改，若有则重新读取并合并。保留手工笔记、无关字段及历史证据，避免把旧缓存在内存中的全文覆盖回去。

使用临时同级文件写入并原子替换，成功后不遗留多份“最终版”笔记。保存后重读核对 Markdown、进度、错误状态和教材链接。更新时间采用实际时间；不把本地成功说成云端同步已完成。无法保存时说明未持久化并给可复制记录，不静默换目录。

恢复课程时按用户指定课程定位当前目录中的对应文件，先读顶部信息、当前进度，再读当前章和相关错题；不扫描无关目录。确认教材身份与附件仍有效；源版本变化则复核覆盖记录，不能继承旧版已读状态。目录不可用时询问新位置，不创建重复课程。

旧版分散笔记如需合并，只合并有明确证据的备课、课堂和错误记录，保留用户已有内容，无法确认的部分标记未核实；保留原文件，不擅自删除。未提供教材或课程时只更新插件规则，不提前创建课程文件或复制不相关材料。

## 记录教学推进

每次完成知识点后，更新该章已实际讲解的内容和下一重点。将“讲解覆盖”与“学生掌握证据”分别记录；不阻碍后续的薄弱点进入待复习列表，不能因此将课程长期停在同一题。用户选择先继续时，未回答的问题仍标记未回答，不记成答错或已掌握。

常规推进轮包含上一回答归纳、下一知识点讲解和新问题；提示、答疑和定向复习轮先完成当前目标，不强行加入新内容：保存时同步记录上一问题的实际结果、新内容已讲状态和新问题待答状态，不能把新问题记为已答或把已讲的新内容仍留在未来计划中。

大主题分块教学时，在当前进度中记录章/节、主题及当前小块、已讲小块和下一块；对应章节记录保留分块路线与组末归纳。细分或合并小块时更新路线并保留已有讲解及错答证据，不将整章误记为已完成，也不为小块另建文件。

## 提问变化与记忆巩固

在课堂记录里简记近期使用的提问形式、对应学习目标与学生实际表现，供后续选择不同思考任务，不额外建立游戏分数或臆测记忆百分比。将需要再次提取的核心知识及薄弱点记为待复习，在后续小块或下次课用不同情境复现；记录是否依赖提示、能否独立回忆或迁移。不要把换题型当作已经掌握，也不预先存入待答题解法。

每章结束在该章内增设“章末综合挑战”小节，记录任务及跨知识点目标、待答/进行中/已反馈/跳过状态、实际回答与纠正证据、需复习的联系。多步任务记录当前步骤；已讲完本章与综合运用证据分别记录。反馈完成后更新下一章起点，未答题不能写成完成，全部内容仍在同一课程文件内。

课堂笔记应记录经过讲解归纳的概念、关系、推理和方法，以及实际使用的例子与学生理解证据，不逐段抄录教材。教材依据、自拟例子、类比与联网补充分清来源；简洁但保留关键条件，不能只留下无解释的术语清单。

选择/判断题记录实际提交的选项及对应答案文本；控件预选不计作答。题型与选项映射应足够还原课堂情境，未提交时保持待答，不提前记录标准答案。

## 学习速度偏好与局部调整

在同一课程文件的“当前进度/学习偏好”中记录课程默认速度（标准/快速/慢慢细学）、来源（学生选择或尚未选择时采用的默认值），以及当前局部覆盖（章/节/知识点、临时速度、恢复时机）。用户说“这部分”只改局部，说“以后”才改课程默认值。恢复课程沿用已记录的选择，不重复询问；局部补讲后依据独立作答证据逐步恢复默认节奏。

记录快速检查的实际题目与回答证据，分别标记已有理解、已简要复习、局部待补和学生要求跳过，不把快速模式或“我会了”的自述当成掌握证明。仅切换速度时保留待答题状态；明确跳过才记未尝试。所有调整继续更新原课程文件，不新增独立速度配置或课程文件。

自动调速默认启用，学生要求固定节奏时关闭。与课程默认偏好分别记录：自动调速开关、当前实际速度、适用概念/局部范围、最近独立回答或提示依赖的简短证据、调整原因及下一检查点。仅在出现新证据或调整时更新，不重复堆积状态；跨章节不直接沿用局部熟练判断。自动加快或放慢不改写学生的课程默认偏好。

错答处理进度随同一错题更新：首次错答→已给提示、等待重答→提示后改正或再次错答后已讲解。保存实际提示、重答和已讲解内容；等待重答时不提前写正确答案。提示后改正仍属于有提示支持的表现，不能记成独立掌握；学生表示仍不会时记录其原意，不虚构第二次错答。恢复课程先接续待重答步骤。

## 章节任务与冒险进度

在对应章节下简记任务目标、关联知识点、当前步骤，以及实际作答后展示的选择结果与理由；区分自拟情境或模拟和真实资料。章末综合挑战承接该任务，不另建重复考试。复课时接续当前步骤和待答/待重答状态，保留既有课程路线。完成任务分别记录独立完成、提示后完成、已讲解与待复习的证据，不用剧情通关替代掌握判断。只在原课程文件更新，不另建存档、分数或冗长剧情日志；学生关闭游戏化后沿用知识进度。

## 教学配图记录

在对应已讲知识点下嵌入实际展示的教材图或本地生成图，使用可解析的相对图片路径（路径需要时编码），图片附件与课程笔记同目录，不另建图片笔记。紧邻图注明类型：教材原图直接提取、教材页面渲染裁图、题目区域裁图、标注版、网络图片、AI 生成示意图或程序绘制示意图。教材图保留教材名、印刷页/PDF 文件页及实际图号；网络图保留来源页、已核实的作者/机构及相关日期；生成图保留解释目标和影响理解的假设。原图与标注版分开，不覆盖原图。只记录实际采用和核验过的图，不预存待答题答案；网络图片无法允许嵌入时存来源链接并说明。保存后核对本地图片存在、相对路径可解析及图注匹配，不声称已验证远程永久可用或云端同步。

## 用学习证据驱动下一轮

在当前进度集中保存简短状态，不重复堆表：章/节/小块与章节任务阶段；待答题及首次作答/已提示待重答/已讲解待检查阶段；相关概念最近的实际能力证据与未决疑点；课程基础速度、局部调整及原因；下一教学目标；优先复习点与触发条件。已正确使用的术语和解释可作为减少重复的依据，但证据只适用于相应知识。旧状态摘要与新位置不一致时一起更新，保留历史回答记录。

复习条目说明具体混淆、最近是否独立完成，以及何时再检验（下一次相关应用、间隔若干小块或下次课）；实际复习后更新证据，独立迁移成功可降低优先级。不要为了填写字段编造复习日期、分数或学生心理。不把老师提供的理由记为学生的推理，也不把尚未作答的新题记录成通过。
