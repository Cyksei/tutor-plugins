# 课程进度与知识笔记分开保存

每门新课在已确认的 Lessons 根目录下，由 `create_course(title)` 自动创建：

```text
课程：<课程中文名>/
├── Note/
│   ├── 笔记：<课程中文名>.md
│   └── 进度：<课程中文名>.md
├── Text/
└── Picture/
```

Note 中的知识笔记最重要，供学生理解和复习；进度记录保存位置、真实作答、正误、提示和续课证据。Text 保存教材 PDF 及其他课程原始资料，Picture 保存已核验的教学图片。必须使用单数 `Picture`，不要另建 Pictures 或把附件散放 Lessons 顶层。同一课按科目集中，不按日期另起课程文件夹。

已有课程沿用实际路径；旧版文件名仍可读取，不为统一名字强行移动或重建。恢复时从课程目录中定位 Note 下的笔记和进度，已存在同名课程先核对身份，不能覆盖或自动添加副本编号。

不用学生每轮提醒记笔记。课堂推进、补讲和纠正完成后，老师主动整理知识；不能仅保存事件便宣称两份文件都已更新。具体工具见 [课程工具](course-tools.md)。遵从“不记录”；不要另建数据库、每章文件或多份最终版。

## 建课与教材

每门新课用真实选项确认目录是否沿用；已明确确认不重复。读取本机设置，不在插件里硬编码设备路径。目录不可用时询问，不创建替代目录。

知识笔记使用课程名或教材中文名，保留原标题、作者、版次、年份、目标与来源位置。从 Note 内的 Markdown 使用 `../Text/<教材文件名>` 和 `../Picture/<图片文件名>` 相对链接（空格等必要时编码）；保留原件，复制后核对文件身份/哈希，不覆盖同名其他教材。来源版本变化需重新核查阅读覆盖。已有附件目录继续使用，核对相对链接可解析。

新课调用 `create_course(title)` 一次建立完整目录及配对文件，再补真实信息和教材链接；不需要再次 split_course。旧课才用 split_course；不要给未读教材预填重点。未知字段如实标记未知。

## 知识笔记：组织知识，不复述课堂流水账

按原教材章节组织，使用自己的话讲清含义与联系，保留正确条件与来源。建议结构：

1. 教材与课程信息、教材链接。
2. 全书概览、知识主线和章节关系。
3. 各章「备课重点（未讲）」与「课堂知识要点（已讲）」分区；通读时整理所有章节详细重点，教学中逐步形成适合该学生的知识笔记。不能把备课完成写成学生已学会。
4. 已完成章节的概念联系和综合归纳。
5. 学生手工补充（已有内容保持原处也可以）。

每个已讲知识点按需要包含：核心结论、为什么、适用条件、与相近概念的区别、方法步骤、一个有帮助的例子、教材位置与实际采用的配图/补充来源。不机械填满模板，也不能只留术语清单。

**按实际学习情况调整详略：**

- 有独立推理或应用证据：写清核心结论、必要条件、关键联系，减少重复解释；不因为答对一次选择题就大量删减。
- 反复混淆、依赖提示或补讲后才理解：在该知识点补上原因、关键中间步骤、对照或例子，写成可反复阅读的解释。
- 错误已在课堂完成纠正：把所得教训改写成「容易混淆：……；区别在于……」，融入对应知识点；不把学生错答原话、时间戳和正误表复制过来。
- 首错正在提示、尚未完成重答：可以整理已讲知识，但不能偷偷在笔记里写本题完整答案或尚未给出的纠正解释。没有适宜知识增量就确认已核对、不改正文。
- 后续独立运用成功：可以合并冗余内容，保留仍有复习价值的解释和必要条件，不自动删除补讲内容或学生手写文字。

更新稳定的知识点条目，合并而非每轮追加同一解释。知识笔记不含课堂台词、小动作、作答时间线、待答选项、进度状态块或自动掌握评分。老师基于进度证据判断详略，工具负责独立保存、冲突检查及更新遗漏提示，不能声称工具会自动判断知识正确性。

配图保留实际核验过的原图/页面裁图/标注版/网络图/生成示意图的类型与来源；教材注明页码及真实图号，网络补充注明可核实的机构、日期、证据状态及链接。教材依据、类比、自拟例子和新研究分清，不能整段抄教材或整篇转载。未讲的拓展标为备课，不冒充已讨论。

## 进度记录：如实留存课堂证据

保存当前章/节/小块、已讲和下一块、当前讲解、待答题及选项、已给提示、错误处理阶段、来源、课程速度与局部调整、下一教学目标及复习触发点。完整阅读覆盖清单、未读/缺失范围和备课检查点也放这里，知识笔记只放整理后的概览与重点。

事件记录保留学生实际答案、正误依据、是否独立/提示后/讲解后完成；准确原话才用引号，否则标为忠实摘要。未提交、预选、沉默、「我不知道」不是错答，未答题不能记为掌握。老师的解释不算学生独立推理。

错题以稳定 error_id 归集首次错误、实际提示、重答与纠正证据；同一混淆复现沿用条目，不造多份。仅给提示时保留待重答阶段，不提前写完整解法。章末综合任务保存当前步骤、实际表现和待复习的联系，任务完成不等于独立掌握。

提示轮不冒充推进；正常推进轮分别记录上一回答的真实结果、新知识已讲、新问题待答。速度、角色、游戏化等偏好保存到进度记录，不打断已有待答题。复习依据具体知识证据，避免用单题或自述推断全章掌握。

## 保存、恢复与旧课拆分

每轮先读进度，按需读当前知识点。先 `record_event` 保存真实状态，再 `read_knowledge` 与 `update_knowledge` 更新受影响的知识点；两个文件各自原子保存，不承诺跨文件或跨设备事务。若进度已保存而笔记失败，返回的 `knowledge_needs_update` 会保持为真；重新读取并补齐笔记，不重记作答、不假称全部成功。纯偏好/提示轮可用空 sections 确认核对，无须制造知识。

新任务通过 `resume_course` 恢复；先接续原题和提示阶段，缺失字段从原记录核实，不重新推断掌握。查看笔记默认打开知识笔记；查看进度/作答/错题则打开进度文件。云同步需要这两个文件与附件都到达本机，本地保存成功不等于云端同步成功。

旧课 `needs_split=true` 时，在该课实际续课/保存时拆分：先完整读取需要保留的知识、来源和手工补充，按上面的知识结构整理为 knowledge_text，再调用 `split_course`。工具将旧文件完整保存在同级进度文件，包括原结构化状态与历史，然后用整理后的知识替换原路径；旧混合内容仅作为进度文件内的历史参考，后续知识更新只进入知识笔记。保留原文件名使现有知识笔记链接继续有效。来源链接沿用原相对路径。

迁移不得因截断摘要漏掉旧知识、删除手工内容、重置待答题或编造已经掌握。工具中断重试可恢复已完整复制的旧文件；目标冲突时保留两者并核实，不能覆盖。只处理正在使用或用户点名的课程，不批量重写其他课程。

每次更新读最新版本，尊重手写和同步改动；CONFLICT 时重读、保留编辑后重新合并，不绕过校验强写。保存失败如实说明，不能另存到未确认目录或系统记忆。
