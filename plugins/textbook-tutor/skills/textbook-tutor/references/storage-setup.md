# 首次使用与本机存放目录

## 触发与读取

第一次调用私教（包括只有“打开私教”“初始化私教”“设置笔记目录”，没有教材），或开始/恢复课程时，用 Python 3 运行本技能 `scripts/storage_settings.py show`。脚本路径从当前技能目录解析，不硬编码安装缓存版本。设置只使用实际文件/工具能力，不通过教学人格索要教材。

偏好存于当前用户 `~/.config/textbook-tutor/settings.json`，不放插件源码、缓存、GitHub 或课程笔记目录；仅含本机默认目录和更新时间，不存教材与学习内容。更新/重装插件保留设置。新设备重新选择，不复制另一设备的绝对路径。配置不可读/损坏时说明并解决，不能当作未设置覆盖。

## 首次选择

未设置时，给出实际绝对路径和用途“课堂笔记、教材副本和教学图片”。候选优先本次明确位置，其次已有课程确认且可访问的位置，否则使用本机用户目录下 `Documents/Lessons`（不存在时明确将创建）。不要扫描整个硬盘或猜 Obsidian 路径。用户已经明确指定位置即视为选择，不重复确认。

调用 `functions.request_user_input_async` 提供真实选项，例如标题“首次使用：课堂笔记、教材副本和图片存放到哪里？\n默认目录：<实际绝对路径>”，选项“使用此目录（推荐）”“选择其他目录”。上下文中有其他真实目录时也可以直接列为选项，标题明确标签对应的绝对路径。预选和超时都不算提交；等待时可独立读取教材，不创建或复制课程文件。

选择其他目录后，仅在当前工具确实支持时打开原生文件夹选择器；否则说明需要粘贴路径，不能假装选择器存在。无可点击输入工具时诚实降级。不要把用户的 shell 转义路径原样存储，先解析并展示真实路径，歧义才询问。

收到实际选择后，运行 `scripts/storage_settings.py set --directory <所选绝对路径>`，参数用安全的结构化调用或 shell 引号传递。该操作创建目标目录并检查可写性，原子保存偏好；运行环境的写入权限仍适用。成功后重读 `show` 核对，再简短告知目录已设置。失败时不声称成功、不静默另存、不创建空课程。仅做目录设置时到此结束，不强制开课。

## 新课、恢复与改位置

- 首次设置同时为当前新课选择目录，不再弹第二次相同确认。
- 后续每门新课仍用“沿用当前路径（推荐）／更改路径”确认；同一课不重复。配置是默认候选，不代表所有未来新课已确认。
- 恢复旧课沿用原文件位置，不因默认目录变化搬移或重建旧课。
- “更改默认存放目录”走同样选择与保存流程，只影响以后新课。明确只改本门课时不改全局偏好；范围不清楚时用选项区分。
- 已保存目录消失或不可访问（如云盘未挂载）时说明，提供重试/更改选择，不自动重建同名本地目录。单独 `show` 永不创建目录。
- 配置已有有效值时不因升级再次要求首次设置。设置写入成功与云端同步是不同的事情。

## 两类课程文件

所选目录是所有课程的根目录，不是某门课的 Note 文件夹。每门新课通过 create_course 在根目录下创建 课程：课程名/Note、Text、Picture；两个 Markdown 放 Note，教材放 Text，图片放单数 Picture。新课确认一次目录即可，不为两份文件重复询问。跨设备续课需同步这两个 Markdown 及教材附件；已有课程子目录沿用原位置。
