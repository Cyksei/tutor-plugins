# 教材私教与教材查找

**简体中文** · [English](README.en.md)

两个可以分别安装、独立使用的 Codex 插件。

| 插件 | 图标 | 用途 |
|---|---|---|
| **教材私教** (`textbook-tutor`) | <img src="plugins/textbook-tutor/assets/icon-cap-centered.png" width="72" alt="蓝色学士帽"> | 从教材备课，以苏格拉底式对话分块教学，记录学习证据并保存续课进度 |
| **教材查找** (`textbook-finder`) | <img src="plugins/textbook-finder/assets/icon-book.png" width="72" alt="蓝色书本"> | 根据内容描述或关键词，在正规来源寻找可下载的教材 PDF，优先新版 |

## 安装

在支持插件市场的 Codex 中运行以下命令，或把本仓库链接交给 Codex，请它安装所需插件：

```sh
codex plugin marketplace add https://github.com/Cyksei/tutor-plugins
codex plugin add textbook-tutor@tutor-plugins
codex plugin add textbook-finder@tutor-plugins
```

可以只安装其中一个。安装或更新后新建任务，让新版本技能和工具加载。要更新已有安装，可把仓库链接交给 Codex，并明确要求更新这两个插件到仓库最新版本。

## 教材查找

调用 `$textbook-finder`，直接描述想学习的内容，不必知道书名。例如：

> 我想了解大脑怎样形成记忆、为什么会遗忘。找适合零基础的教材 PDF，要求正规来源、完整可下载，优先新版。

- 核对出版社、高校、官方机构和开放教材平台的来源与资源归属。
- 区分完整 PDF、分章下载、试读、仅在线阅读和受限资源。
- 在符合主题、语言和学习基础的候选中，按实际出版或修订年份由新到旧排列。
- 提供来源页和已核验的下载入口；用户要求时下载并检查文件。
- 独立使用，不初始化课堂目录、不创建课程笔记、不自动开课。

## 教材私教

调用 `$textbook-tutor` 并提供教材，或要求恢复已保存课程。

- 阅读教材并整理全书路线、章节重点，再按章节分块教学。
- 每次讲一个小要点并配一个相关问题，理解后反馈并推进。
- 首次答错先提示；仍不会再解释，支持直接讲解、跳过和固定节奏。
- 用 `plan_teaching_turn` 预检教学动作，保存时再次检查待答题和提示阶段。
- 按概念记录实际学习证据，区分独立完成与提示后完成，给出局部调速和复习建议。
- 展示教材配图，按需联网补充，并标明来源。
- 每门课程分开保存知识笔记与进度记录：知识笔记随课堂整理，理解充分处精练、困难处详解；实际回答、正误与提示状态保存在进度文件。
- 自动建立课程文件夹，按 Note、Text、Picture 分类保存；旧课保留原始记录后整理拆分。
- 使用 `save_checkpoint` / `resume_course` 保存和恢复具体内容、待答题、选项与提示阶段。

默认普通对话控制。可直接说“慢一点”“直接讲”“固定速度”“关闭角色”“复习”“保存当前进度”。可选面板工具保留，但不自动打开。

首次使用选择本机课堂文件目录，每门新课再确认位置。跨设备续课需要同步整个课程文件夹（知识笔记、进度记录、教材和图片），在另一台设备选择实际目录；插件不会自动完成云端同步。

## 课程文件结构

每门新课确认根目录后自动创建；同名课程不会被覆盖。知识点更新合并到原条目，不堆积课堂流水账。

```text
Lessons/
└── 课程：课程名/
    ├── Note/
    │   ├── 笔记：课程名.md
    │   └── 进度：课程名.md
    ├── Text/
    └── Picture/
```

教材存 Text，教学图片存单数 Picture，Note 内的笔记通过相对链接引用附件。进度与知识分别保存；如果知识更新失败，续课时会提示补齐，不重复登记学生作答。尚在提示阶段时，不在知识笔记提前泄露待答题解法。

## 运行条件与边界

教材查找使用 Codex 当前可用的联网及下载能力，无额外服务依赖。教材私教包含本地 stdio MCP 服务，使用 Codex 随附 Python 环境；当前启动器适配 macOS，未验证 Windows，不要求另装 Python 或数据库。

教材解析、图片展示/生成和交互控件取决于当前环境可用的工具与权限。模型负责理解和讲解，程序检查流程与记录一致性，不能自动保证答案事实正确或模型每次都调用工具。工具不可用时如实说明并使用可用替代。

课堂使用角色扮演，知识准确性与学生选择优先于角色表达。

## 文件与隐私

仓库包含两个插件的技能规则、工具代码、测试与实际使用的图标，不包含教材、课程笔记、账号凭据或本机目录配置。请将私人课程文件保存在仓库外。

课程工具测试仅使用临时文件：

```sh
python3 -m unittest discover -s plugins/textbook-tutor/tests -v
```
