# 教材私教 · Textbook Tutor

用于 Codex 的中文教材私教插件。通读教材并整理章节路线，采用温迪风格的角色教学、苏格拉底式提问和轻量知识冒险。

## 安装

在支持插件市场的 Codex CLI 中运行：

```sh
codex plugin marketplace add https://github.com/Cyksei/tutor-plugins
codex plugin add textbook-tutor@tutor-plugins
```

安装后新建任务，调用 `$textbook-tutor` 并提供教材。也可以把本仓库链接交给 Codex，请它安装插件。

## 使用

首次使用选择本机 Lessons 保存目录；每门新课再次确认目录。每门课程使用一个持续更新的中文 Markdown 笔记，教材和图片附件保存在同一目录。跨设备续课需要自行同步这些课程文件，再让私教读取原笔记。

- 先通读教材，整理各章重点，再依次教学。
- 每次讲一个小要点并配一个问题，反馈后自动推进。
- 首次答错先提示，重答仍错再讲解。
- 根据独立回答与提示依赖自动调速，也可手动指定或固定节奏。
- 章节任务、情境决策与章末综合挑战帮助理解和迁移。
- 教材原图、网络图片及生成示意图分别标明来源。
- 记录实际错答、提示、自我修正及复习进度。

可说“慢一点”“直接讲”“关闭角色”“关闭游戏化”“查看课堂笔记”调整课堂。

## 运行条件

这是技能插件，不包含独立模型服务。文件读取、PDF 解析、联网搜索、图片展示/生成和点击选项取决于当前 Codex 环境可用的工具与权限；缺少工具时会说明并采用可用替代。插件本身不自动同步教材或笔记，也不保证学习效果。

角色相关内容为非官方角色扮演，不代表其IP或权利方。知识讲解和证据判断优先于角色表达。

## 文件与隐私

仓库仅包含插件规则、最终图标和安装说明；不包含教材、课程笔记、账号凭据或设备专属保存路径。请将课程文件保存在仓库外，勿提交个人学习资料。
